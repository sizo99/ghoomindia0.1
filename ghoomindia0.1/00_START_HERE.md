## 🔧 Quick Setup

### Step 1: Organize Files
```
Create a folder structure:

your-project/
├── index.html              (renamed from responsive.html)
└── images/
    ├── hero-full.jpg
    ├── logo-green.png
    ├── trek-poster.jpg
    └── (other images...)
```

### Step 2: Update Image Paths
Open `index.html` and find:
```html
style="background-image:url('data:image/svg+xml,..."
```

Replace with:
```html
style="background-image:url('./images/hero-full.jpg');"
```

(See `SETUP_GUIDE.md` for complete list)

### Step 3: Test Locally
```
Open index.html in browser
Press F12 → Click device icon → Select iPhone/Android
Scroll through entire page
Check all buttons work
```

## 💡 Pro Tips

1. **Mobile First** - Always test on actual phone, not just DevTools
2. **Chrome DevTools** - F12 → Device icon is your best friend
3. **Hard Refresh** - Ctrl+Shift+R when testing
4. **Image Compression** - TinyPNG.com to reduce file sizes
5. **Test Landscape** - Some users rotate their phones
6. **Update Regularly** - Keep website fresh
7. **Monitor Performance** - Use Google Analytics
8. **Backup Files** - Always have a copy
